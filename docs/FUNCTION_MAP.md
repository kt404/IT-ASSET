## Inline handler coverage

Static markup retains handlers for login/logout, notification/report/backup, allocation/return/borrow forms and filters, add-device/import, inventory/assets, employee lookup, category/department/user administration, modal close, and manual sync. Generated markup retains quantity controls, selection removal, record/device detail, edit/delete confirmations, borrow return, PDF printing, Excel confirmation, and category field drag/drop. Because scripts are classic scripts and declarations remain top-level, these functions remain callable by `window` event-handler scope.
